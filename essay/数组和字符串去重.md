# 数组和字符串去重：先定义“相同”

适用范围：清理表单选项、合并接口结果或规范化文本；关键原则：先说明按值、按键还是按用户可见字符判重；当前代码示例：下面分别使用 Set、键函数和 Intl.Segmenter；常见误区/边界：对象引用不等于结构相同，字符串的一个字符也不一定是一个用户感知字符；官方参考：[MDN Set](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Set)。

## 基础值：Set 保留首次出现顺序

~~~js
const values = ["a", "b", "a", NaN, NaN, 0, -0];
const uniqueValues = [...new Set(values)];

console.log(uniqueValues); // ["a", "b", NaN, 0]
~~~

Set 按 SameValueZero 比较基础值，因此 NaN 会被视为同一个值，0 和 -0 也会合并。它不会深比较对象：两个内容相同但分别创建的对象仍是不同引用。

## 对象列表：明确业务键

~~~js
function uniqueBy(items, keyOf) {
  const seen = new Set();

  return items.filter((item) => {
    const key = keyOf(item);
    if (seen.has(key)) {
      return false;
    }
    seen.add(key);
    return true;
  });
}

const users = [
  { id: "u1", name: "Ada" },
  { id: "u2", name: "Lin" },
  { id: "u1", name: "Ada (new)" },
];

console.log(uniqueBy(users, (user) => user.id));
~~~

这个实现保留每个 id 的第一条记录；若业务需要“最后一条覆盖前一条”，应显式用 Map 写出该规则，并在测试中固定预期。

## 文本：按可见字素拆分

~~~js
function uniqueGraphemes(input, locale = "zh-CN") {
  const segmenter = new Intl.Segmenter(locale, { granularity: "grapheme" });
  const units = Array.from(
    segmenter.segment(input.normalize("NFC")),
    ({ segment }) => segment,
  );

  return [...new Set(units)].join("");
}

console.log(uniqueGraphemes("咖咖啡啡"));
~~~

Array.from 能正确处理大多数 Unicode 码点，但组合字符、变体选择符和部分表情需要按字素处理。是否应做大小写折叠、去空白或 Unicode 规范化，是产品规则，不应被隐藏在“去重”函数里。
