# 惰性求值：只消费真正需要的数据

适用范围：处理长列表、流式数据或可能无限的数据源；关键原则：把产生、转换和消费拆开，直到消费者请求下一个值才计算；当前代码示例：下面用生成器按需计算平方数；常见误区/边界：惰性不会自动让单次计算更快，必须有明确的停止条件；官方参考：[MDN 迭代器与生成器](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide/Iterators_and_generators)。

惰性求值的价值是避免无效工作，而不是替代算法设计。比如只需要小于某个上限的结果时，没有必要先创建一个巨大的中间数组。

## 用生成器组成按需管道

~~~js
function* integers(start = 1) {
  let current = start;
  while (true) {
    yield current++;
  }
}

function* map(iterable, mapper) {
  for (const value of iterable) {
    yield mapper(value);
  }
}

function* filter(iterable, predicate) {
  for (const value of iterable) {
    if (predicate(value)) {
      yield value;
    }
  }
}

function* takeWhile(iterable, predicate) {
  for (const value of iterable) {
    if (!predicate(value)) {
      return;
    }
    yield value;
  }
}

const oddSquaresBelowTenThousand = takeWhile(
  filter(map(integers(), (n) => n ** 2), (n) => n % 2 === 1),
  (n) => n < 10_000,
);

let total = 0;
for (const value of oddSquaresBelowTenThousand) {
  total += value;
}

console.log(total);
~~~

上例中每个值只在 for...of 需要它时才经过 map 和 filter，也没有把全部结果展开成数组。消费者停止迭代时，生成器会停止继续产生值。

## 什么时候不该使用

如果数据很小、需要随机访问、或后续逻辑必须反复遍历全部结果，普通数组通常更直观。对无限序列尤其要警惕：没有 take、takeWhile、超时或取消信号的过滤管道，可能永远找不到下一个满足条件的值。

异步数据源可使用 async generator 和 for await...of，仍应把取消、网络错误和资源释放放在迭代边界处理，而不是假定懒加载会自动解决这些问题。
